# 阶段二：任务编排与基础执行

## 1. 目标与依赖

基于阶段一接口资产，完成固定参数任务的编排、顺序执行及结果查询。验收不依赖响应参数提取和实时进度。

## 2. 任务管理与步骤

- 任务属于项目，支持列表、创建、编辑、复制、删除和详情；名称必填且项目内唯一。
- 配置名称、描述、HTTP/HTTPS 运行地址、请求超时、固定全局参数和有序步骤。地址可含路径前缀，不含 query 或 fragment。
- 超时默认 30 秒，可设为 1～300 秒。草稿可无步骤，运行至少一个步骤。
- 只能选择本项目接口，绑定具体 YAML 版本；页面显示文件、版本、方法及路径。
- 步骤有稳定 ID 和展示序号，支持添加、复制、移除及排序；同一接口可多次添加。
- YAML 更新不自动修改任务；编辑时提示存在新版本，显式重新选择后重新校验参数。

## 3. 固定参数与绑定

- 全局参数包含名称、类型、固定值及敏感标记，名称任务内唯一；支持 string、integer、number、boolean、object、array。
- 接口参数和 JSON 请求体字段可配置字面值或整体引用一个全局参数，保存为结构化绑定，保留类型；不支持字符串内部模板拼接。
- 保存和运行前校验必填、类型、引用存在；可选字段未配置则不发送。接口默认值可首次填入，用户可修改。
- path、query 正确 URL 编码；query 数组以重复键发送，例如 `id=1&id=2`；对象 query 暂不支持，必须明确报错。
- 地址前缀与接口路径正确拼接；JSON 对象和数组按结构序列化。
- 认证 header 可配置字面值或参数引用；header 不得覆盖 HTTP 方法、请求地址等执行配置。

## 4. 运行规则

- 点击运行先校验配置；失败不发送请求。成功后保存运行记录和不可变配置快照。
- 修改任务或 YAML 不影响已创建运行；每次运行独立初始化固定参数。
- 同一任务有未结束运行时拒绝重复启动；不同任务可以独立运行。
- Pipeline 1 准备环境和固定参数，Pipeline 2 顺序执行，不并行、不自动重试、不自动跟随重定向。
- 每步发送前先持久化请求记录，发送后保存响应；刷新或关闭页面不终止服务端执行。
- 运行状态：待运行、运行中、成功、失败。步骤状态：待执行、执行中、成功、失败、已跳过。
- HTTP 2xx 成功；其他状态、连接错误及超时失败。失败后后续步骤跳过。
- 服务重启将遗留未完成运行标记为执行中断失败，不自动续跑，避免重复请求。
- 删除任务需确认并删除关联运行记录；运行中的任务禁止删除。

## 5. 记录与页面

- 请求记录包含运行及步骤 ID、序号、方法、实际 URL、请求头和体、响应状态码及头和体、开始/结束时间、耗时和错误原因。
- 敏感参数在页面及日志脱敏；Authorization、Cookie、Set-Cookie 头默认脱敏。
- 交付任务列表、编辑及排序、参数编辑、运行入口、历史列表、运行详情和请求详情。本阶段手动刷新查询即可。

## 6. 验收标准

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| P2-01 | 编排三个接口、排序、保存再打开 | 步骤、版本、参数及配置一致 |
| P2-02 | 参数绑定到 path、query、header、JSON 字段 | 模拟服务收到正确编码和类型，结构未丢失 |
| P2-03 | 缺必填、引用不存在、类型错误 | 明确定位错误，无 HTTP 请求发出 |
| P2-04 | 三步均返回 2xx | 按序各执行一次，运行成功，记录完整 |
| P2-05 | 第二步返回 500、超时或连接失败 | 第二步失败，第三步跳过，原因可区分 |
| P2-06 | 运行中修改任务、更新 YAML、刷新页面 | 原快照继续执行，记录不变 |
| P2-07 | 同任务重复启动，另一个任务同时运行 | 同任务仅一个活动运行，不同任务数据隔离 |
| P2-08 | 执行中重启服务 | 运行标记中断失败，不重复执行 |
| P2-09 | 使用敏感参数并查看详情、日志 | 请求正常发送，敏感值不直接展示 |

提供可记录顺序和参数、返回成功或失败、模拟延迟的 HTTP 服务。验收不依赖真实接口，服务重启后运行历史仍可查询。
